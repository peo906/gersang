# 제작으로부자되자

거상 **청룡 서버**의 제작 재료비와 육의전 판매 매물가를 비교하는 Windows 로컬 프로그램입니다.
거니버스에서 제작법을, 거타에서 재료·완제품 매물을 읽습니다. 외부 조회는 별도의 Microsoft Edge 창에서 진행합니다.

![프로그램 아이콘](assets/app-icon.png)

## 다른 대화에서 이어서 작업하기

**[HANDOFF.md](HANDOFF.md)를 먼저 읽으세요.** 구현 현황, 파일 역할, 계산 규칙, 데이터 형식, 검증 결과와 제한사항이 있습니다.
새 대화에 이렇게 요청하면 됩니다.

## 주요 기능

- 제작 재료를 트리로 표시하고 재료별 구매 / 하위 재료 제작 / 자동 비교 선택.
- 최저가 매물의 **실제 수량**으로 비용 계산. 부족하면 다음 페이지를 필요한 만큼 조회.
- 전체 매물도 부족하면 과거 기록의 최신 첫 금액으로 부족분만 추정하고 매물부족 표시.
- 완제품 판매 매물가와 제작원가·차익 비교. 현재 완제품 매물이 없으면 과거 최신순 첫 페이지 단가의 산술평균 사용.
- 보유 재료 차감, 최근 조회 5개, 마지막 시세 조회 시각, 한국 날짜 기준 예상 제작 완료일.
- 제작법·가격을 JSON으로 저장하며 사용자 요청 없이 자동 갱신하지 않음.
- 조회 완료 후 **1.5초** 대기. 검색 결과가 명시적으로 없을 때만 띄어쓰기·호환 한자 대체 검색, 최대 8개 이름.

## 소스로 실행

Windows 10/11 x64, Python 3.12, Microsoft Edge가 필요합니다. 처음에는 `start.bat`를 실행하면 전용 환경을 준비하고 웹 화면을 엽니다.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe app.py
```

브라우저에서 `http://127.0.0.1:8765`를 사용합니다. 종료는 실행 창에서 Ctrl+C.
데스크톱 실행 파일과 포터블 묶음 생성 방법은 **[BUILD.md](BUILD.md)** 에 있습니다.

## 설치 없이 사용

별도로 만든 포터블 ZIP 전체를 압축 해제한 뒤 `제작으로부자되자.exe`를 실행합니다. Python과 WebView2 구성요소는 묶음에 포함됩니다.
외부 조회용 Edge는 PC에 있어야 합니다. 실행 파일만 이동하면 안 됩니다.
**이 소스 저장소에는 포터블 ZIP·가상환경·DLL·개인 DB가 포함되지 않습니다.** 저장소 ZIP은 실행용 포터블 ZIP과 다릅니다.

## 검증

```powershell
.venv\Scripts\python.exe -m unittest discover -p "test_*.py" -q
node test_ui.js
```

2026-10-26 기준 Python 61개 테스트와 오프라인 UI 검증을 통과했습니다.
포터블 계산·외부 Edge의 빈 페이지 실행·동봉 WebView2 실행·앱 종료를 이 PC에서 확인했습니다.
다른 PC 실행과 최종 버전의 실제 거타 조회는 검증하지 않았습니다.

## 저장 정보와 공유

자료는 `data/`에 저장됩니다. DB·조회 기록·보유 수량·브라우저 쿠키는 Git에 올리지 않습니다.
친구에게는 최초 배포 ZIP을 보내고, 사용 중인 `data/browser`나 `data/desktop`을 공유하지 마세요.
아이콘은 사용자가 제공한 각성 다문천왕 이미지를 참고해 생성했습니다. 원작 캐릭터와 제3자 구성요소의 권리는 각 권리자에게 있습니다.
소스에 별도의 오픈소스 사용권을 부여한 것은 아니며 WebView2 SDK 라이선스는 `desktop/WebView2-LICENSE.txt`에 있습니다.

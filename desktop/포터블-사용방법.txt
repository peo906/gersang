제작으로부자되자 · 포터블

1. ZIP 파일 전체를 내 PC의 일반 폴더에 압축 해제하세요.
2. 제작으로부자되자.exe를 실행하세요. 별도 Python 설치는 필요 없습니다.
3. 자료 조회가 필요하면 외부 Microsoft Edge 창이 열립니다.

Windows 10/11 64비트용입니다. 외부 조회용 Microsoft Edge가 필요합니다.
계산 화면용 WebView2는 설치된 최신 버전을 우선 사용하며, 없으면 동봉한 버전을 사용합니다.
Python 실행 환경과 WebView2 구성요소를 포함하여 용량이 큽니다.
네트워크 공유 폴더나 ZIP 안에서 직접 실행하지 말고, 쓰기 가능한 로컬 폴더에서 실행하세요.
실행 파일만 옮기지 마세요. engine, WebView2Runtime, DLL 등 모든 파일이 함께 있어야 합니다.

공유본에는 제작자의 조회 기록·브라우저 쿠키·로그인 정보·보유 수량이 없습니다.
처음에는 빈 화면이며 검색을 요청할 때부터 자료를 수집합니다.
자료와 설정은 각자 압축을 푼 폴더의 data 안에 저장됩니다.
data/browser와 data/desktop에는 개인 브라우저 정보가 생기므로 사용한 폴더째 다시 공유하지 마세요.
친구에게는 최초 배포 ZIP 원본을 보내세요.

조회 완료 후 1.5초를 기다립니다. 원래 검색 결과가 없을 때만 띄어쓰기·호환 한자 후보를 최대 8개 확인합니다.
거타가 접근을 거절하면 자동으로 우회하지 않고 조회를 중단합니다.
일반 브라우저에서 접속되더라도 조회용 Edge에서는 제한될 수 있습니다.
이 PC에서 오프라인 계산·외부 Edge 실행을 점검했으며 다른 PC와 실제 거타 조회는 별도 확인이 필요합니다.

두 버전이 동시에 실행되면 충돌합니다. 기존 프로그램을 종료한 뒤 실행하세요.
앱을 닫으면 계산 서버도 종료됩니다. 오류 확인: data/desktop.log.

업데이트: 새 버전을 새 폴더에 풀고, 이전 앱이 종료된 상태에서 data 폴더를 복사하면 자료를 옮길 수 있습니다.
동봉한 WebView2 고정 버전은 155.0.4283.62이며 자동 갱신되지 않습니다. 설치된 최신 Runtime이 있으면 그것을 우선 사용합니다.
외부 구성요소의 라이선스는 licenses 및 WebView2Runtime 폴더에 있습니다.
